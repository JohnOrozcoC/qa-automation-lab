# QA Automation Lab

Laboratorio práctico para aprender y construir un framework moderno de **Quality Engineering** con enfoque Enterprise.

El objetivo no es solamente aprender herramientas, sino comprender la arquitectura, las buenas prácticas y el ciclo completo de automatización de pruebas utilizado en proyectos reales de banca digital, fintech y aplicaciones empresariales.

---

## Tecnologías

- Python
- Playwright
- Pytest
- Page Object Model (POM)
- Git & GitHub
- GitHub Actions (CI)

---

## Capacidades implementadas

- ✅ Automatización Web con Playwright
- ✅ Page Object Model (POM)
- ✅ Pytest Fixtures
- ✅ Pytest Markers
- ✅ HTML Reports
- ✅ Git Version Control
- ✅ GitHub Repository
- ✅ GitHub Actions CI Pipeline
